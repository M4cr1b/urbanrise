================================================================================
                            COLOR SCHEME LEGEND
================================================================================

🟦 PRIMARY: Headers, titles, main CTAs
  (Example: "ADJIRINGANOR DUPLEX", ₵ Price, Primary Phone Button)

🟩 SECONDARY: Facilities, positive actions
  (Example: Facility pills, amenities section)

🟪 TERTIARY: Sustainability, environmental info
  (Example: Green features, eco section)

⬜ BACKGROUNDS: Gradient surfaces
  (Example: surface → surface-container colors)

⬛ TEXT: Good contrast
  (Example: on-surface for primary, on-surface-variant for secondary)

================================================================================
                          INTERACTIVE ELEMENTS
================================================================================

HOVER EFFECTS:

1. Panel Cards:
   Default:  Light border, subtle shadow
   Hover:    Darker border, larger shadow

2. Agent Phone Buttons:
   Default:  Gradient background
   Hover:    More vibrant gradient, enhanced shadow

3. Facility Pills:
   Default:  Muted background
   Hover:    Brighter background

4. Stat Cards:
   Default:  Subtle ring effect
   Hover:    Enhanced shadow, brighter ring

STICKY ELEMENTS:

- Agent Contact Card stays visible while scrolling on desktop
- Ensures easy access to phone numbers throughout viewing

RESPONSIVE BEHAVIOR:

- Mobile: Single column, all elements stack
- Tablet: 2-column grid for specs, agent below
- Desktop: 3-column layout with sticky agent card on right
